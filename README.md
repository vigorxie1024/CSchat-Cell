# CSchat-Cell · 第三谱系（细胞级）碳硅联合劳动力产品

> 契约先行：实现严格遵循 [CONTRACT-v0.1.md](CONTRACT-v0.1.md)。
> **契约断言 18/18 通过**（`node contract-proof.js http://127.0.0.1:8012`）。

## 这是什么

面向 1–50 个碳基人的「最小完整战斗细胞」：碳基主理人下一句话 → 中枢（nucleus）拆解 → 智能体执行 → 任务树在 Chat 里可见 → 碳基人审批/放行。

**不是更复杂的群聊工具**，是"一句话召唤千军万马"的最小闭环。

## 怎么跑（零依赖）

```bash
# 不需要 pip install 任何东西
set CELL_PORT=8012          # Windows
python server_cell.py

# 浏览器打开
http://127.0.0.1:8012/
```

可选环境变量：

| 变量 | 默认 | 作用 |
|---|---|---|
| `CELL_PORT` | 8000 | 监听端口 |
| `CELL_BUDGET` | 200000 | 群预算（tokens） |
| `CELL_APPROVAL_TOKENS` | 20000 | 单节点审批阈值 |
| `CELL_APPROVAL_TTL` | 1800 | 审批有效期（秒） |
| `DEEPSEEK_API_KEY` | 空 | 接真模型时用；不配则走 Mock 拆解 |
